# 🎧 Spotify Data Analysis Dashboard (Power BI)

## 🚀 Project Overview  
Designed and developed an interactive **Spotify analytics dashboard** using Power BI to analyze music streaming data, artist performance, and track-level insights.  
The dashboard transforms raw streaming data into **meaningful visual insights**, enabling better understanding of music trends and audience preferences.

---

## 🎯 Objective  

- Analyze track and artist performance using streaming data  
- Identify trends in music popularity over time  
- Evaluate audio features influencing track success  
- Enable interactive exploration of music analytics  

---

## 📂 Dataset Description  

The dataset includes key attributes such as:  
- 🎵 Track Name & Artist  
- 📅 Release Date (Year, Month)  
- 🔥 Popularity Score  
- ▶️ Total Streams  
- 🎧 Playlist & Chart Presence  
- 🎚 Audio Features (Energy, Danceability, Valence, Tempo)  

Spotify datasets typically include metrics like streams, popularity, and playlist reach, which help analyze music performance and listener behavior.

---

## 🔄 Data Processing  

- 🧹 Performed data cleaning using Power Query (handled nulls, removed duplicates, corrected data types)  
- 🔗 Built data relationships for structured analysis  
- 📊 Created calculated measures using DAX (Total Streams, Avg Popularity, Track Count)  
- 📈 Transformed raw data into analytical metrics for reporting  

---

## 📈 Key Insights  

### 🎤 Artist Performance  
- Identified top-performing artists based on total streams and track presence  
- Highlighted artists contributing significantly to overall popularity  

### 🎵 Track Analysis  
- Determined most streamed and most popular tracks  
- Analyzed distribution of songs across playlists and charts  

### 📅 Trend Analysis  
- Observed release trends over time, identifying peak years of music production  
- Tracked changes in music popularity across different periods  

### 🎚 Audio Feature Insights  
- Analyzed features like **energy, danceability, and valence** to understand song characteristics  
- Identified patterns between audio features and track popularity  

### 📊 Popularity & Engagement  
- Compared popularity scores with streaming performance  
- Identified factors influencing audience engagement  

---

## 💼 Business Impact  

- 🎯 Helps identify high-performing artists and tracks for promotion  
- 📈 Supports data-driven decisions in music marketing and playlist curation  
- 📊 Enables better understanding of listener preferences  
- ⚡ Simplifies large streaming datasets into actionable insights
